# Aironet Mobile

Мобильный личный кабинет абонента **Aironet**: проверяйте баланс и тариф, смотрите статус подключения и переходите к оплате — прямо со смартфона.

## Возможности

- Вход в личный кабинет Aironet
- Просмотр баланса, тарифа, даты списания и статуса блокировки
- Сохранение учётных данных по желанию пользователя в защищённом хранилище устройства
- Переход на страницу оплаты Aironet

## Технологии

- .NET 10 и .NET MAUI
- C# и XAML

## Запуск

Установите .NET 10 SDK и workload MAUI, затем откройте `AironetMobileApp.slnx` в Visual Studio 2026 или выполните в корне репозитория:

```bash
dotnet build AironetAndroidApp/AironetMobileApp.csproj -f net10.0-android
```

Запустите приложение на Android-устройстве или эмуляторе. Для входа используются учётные данные личного кабинета Aironet.
